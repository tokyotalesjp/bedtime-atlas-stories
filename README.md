# Bedtime Atlas — Calm Bedtime Folktales, Read Aloud

An index of the **Bedtime Atlas** YouTube channel: classic folktales from around the world, retold and read aloud in calm English for adult listeners. Quiet from start to finish — no learning segments, no excitement, just a story and a level voice to end the day.

## About

Each episode is an original English script based on a public-domain or clearly licensed source tale. Standard episodes run 12–15 minutes; compilations gather them into longer listening sessions.
